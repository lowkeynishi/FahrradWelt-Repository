Description:
Es handelt sich um einen Fahrradshop mit Bildern und einem Link. Ganz unten auf der Seite befindet sich ein Formular, in dem die Kunden ihre persönlichen Daten sowie das ausgewählte Fahrrad eintragen können. Nach dem Klick auf "Absenden" werden die Daten an ein CGI-Skript übermittelt, das die Benutzer auf eine neue HTML-Seite weiterleitet. Dort werden die ausgewählten Fahrradeigenschaften ausführlich dargestellt.
